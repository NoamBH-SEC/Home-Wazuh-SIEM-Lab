# Cybersecurity Portfolio

Welcome to my cybersecurity portfolio. This repository documents hands-on security projects focused on security operations, endpoint monitoring, detection engineering, adversary emulation, incident response, and defensive automation.

The goal of this portfolio is to demonstrate practical experience building security labs, generating telemetry, detecting suspicious activity, investigating alerts, and documenting repeatable defensive workflows.

\---

## Responsible Use

All adversary-emulation activity in this portfolio is performed only inside an isolated, personally owned lab environment. The techniques are used for defensive education, detection validation, and incident-response practice.

No testing should be performed against systems without explicit authorization.

This repository is continuously updated as I build additional detections, attack simulations, response workflows, and security documentation.
